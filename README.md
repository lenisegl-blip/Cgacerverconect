# CGACERV CONNECT

Portal estático para o grupo CGACERV. Abra `index.html` no navegador ou publique esta pasta no GitHub Pages.

## Publicar no GitHub Pages
1. Crie um repositório no GitHub chamado `cgacerv-connect`.
2. Envie `index.html` para a raiz do repositório.
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Escolha `main` e `/ (root)` e salve.
6. Aguarde a URL do GitHub Pages aparecer nessa tela.

## Limitação importante
Este projeto é apenas um portal para identificar o jogador e copiar os endereços. Ele não autentica membros, não mantém uma lista privada e não substitui o BedrockTogether. Uma página estática não consegue abrir uma conexão UDP do Minecraft nem acordar o servidor por conta própria. Para isso, seria necessário um serviço de ponte UDP executando em uma hospedagem compatível.

O apelido digitado é usado somente na página e não é enviado nem armazenado em servidor.
